# Greyfoundry

Open-source systems, infrastructure, and developer tooling built for reliability, scale, and real-world use.

## Current project

### [Elah](https://github.com/greyfoundry/elah)

Elah is an early-stage distributed orchestration and ownership layer for Minecraft worlds. Its current 0.0.3 Observer milestone provides deterministic, read-only inspection of offline Minecraft Java Anvil worlds. It is not yet a playable distributed cluster.

## How we work

- Safety, correctness, and explicit failure behavior come before feature volume.
- Each repository defines its own architecture, invariants, contribution process, security policy, and release gates.
- Access follows least privilege. Triage manages community workflow, maintainers guide projects, security managers handle alerts, and organization owners retain destructive administration.
- Technical decisions are recorded in issues, pull requests, and architecture decision records where appropriate.
- Security reports follow the private reporting instructions in each repository's `SECURITY.md`.

# Support

Greyfoundry repositories are maintained in public wherever practical.

## Project questions

Use the affected repository's issue tracker for reproducible bugs and scoped feature requests. Use GitHub Discussions when the repository enables it for questions, design discussion, or community help.

Before opening a new thread:

1. Read the repository's README and documentation.
2. Search existing issues and discussions.
3. Include the project version, environment, expected behavior, observed behavior, and a minimal reproduction when relevant.

## Security

Do not use public support channels for vulnerability details. Follow the repository's SECURITY.md or the Greyfoundry default security policy.

## Funding

Ko-fi is a funding channel, not a technical-support queue. Supporting Greyfoundry does not purchase priority, private support, roadmap control, or a guaranteed response time.
